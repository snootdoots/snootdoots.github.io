Agentic Contract Parser

As part of my internship at GE Vernova under the Data Science and Automation team, I was tasked with creating an agentic contract processing workflow. Contracts are typically difficult for LLMs to understand because their amendments require continuous information replacement - e.g., if an amendment is added, the knowledge from the original contract needs to be updated (appended/replaced/updated). I thus created an agentic contract parsing workflow which leverages LangChain for chunking and structured JSON output, multithreading for concurrency/faster processing times, persistent JSON and ChromaDB storage for clauses and vectorstore, respectively, RegEx for text cleaning, and few-shot prompting for response clarity.

Dog Classifier

As a part of my EECS445 project, I built a dog breed classifier to distinguish Golden Retrievers from Collies using a dataset of thousands of real-world dog images. I implemented and compared the performance of convolutional neural networks (CNNs), CNNs with transfer learning, and vision transformers (ViTs) to find the most generalizable approach. Tested on a heldout challenge set, I achieved over 81% AUROC by using transfer-learning-based CNN architecture with feature engineering and data augmentation.

ask485

This project was done for my EECS 485: Web Systems class, where I built a scalable search engine similar to Google. I used Python and Hadoop Streaming to implement a series of MapReduce programs that created a segmented inverted index of web pages, supporting efficient full-text search with tf-idf scoring and PageRank-based link analysis. I then built an Index server API following RESTful protocol that queries the index and returns ranked search results in JSON format. Finally, I created a Search server using HTML/CSS/JavaScript to render a responsive frontend that communicates with the backend via REST calls, providing functionality like keyword search, dynamic page rendering, and Google-style result formatting. The architecture followed a Service-Oriented pattern to ensure scalability and separation of concerns between indexing, querying, and rendering components.

AutoWater

In this project, I designed and built a solar-powered automatic plant waterer from scratch using Arduino and TinkerCAD. The device uses moisture sensors to determine when to water the plant, weight sensors to determine when the tank needs more water, and a bluetooth device to notify the user when the water needed to be refilled. This would ensure that they receive the right amount of water without human intervention.
